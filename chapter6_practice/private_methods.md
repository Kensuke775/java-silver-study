# 6章 privateメソッドと動的束縛 問題集

## 前提知識メモ

- オーバーライドが成立する大前提は「親のメソッドが子から**見えている**（可視である）」こと
- `private`メソッドは宣言されたクラスの外から一切見えないため、子クラスから見ると最初から可視性がなく、オーバーライドの対象になり得ない
- 子クラス側が親と同じシグネチャ（名前＋引数）のメソッドを追加しても、それは継承・オーバーライドの対象外の**無関係な別メソッド**として扱われる
- **子クラス側のアクセス修飾子を`public`のように広げても関係ない**。オーバーライドの可否を決めるのは「親のメソッドが子から見えているかどうか」であって、子側の修飾子ではない。親が`private`で不可視である時点で、子が`private`・`public`・無印のどれで同名メソッドを定義しても、オーバーライドは成立しない
- オーバーライドが成立しない＝継承チェーンに入らない＝動的束縛（実行時の型に応じたメソッド選択）の対象外になる
- 結果、親クラス自身のメソッド内から呼ばれる`private`メソッド呼び出しは、常にそのメソッドが**宣言されたクラス自身**の実装に静的に決定される。呼び出し元オブジェクトの実際の型（`Child`など）が何であっても変わらない

---

## 問題6-6：privateメソッドはオーバーライドされるか（選択式）

```java
class Parent {
    private void greet() { System.out.println("Parent"); }
    void run() { greet(); }
}
class Child extends Parent {
    // insert code here
}
public class Main {
    public static void main(String[] args) {
        new Child().run();
    }
}
```

5行目（`// insert code here`）に入れるコードとその説明として**正しいものを2つ**選んでください。

**A.** 何も書かない
「`Parent.run()`内の`greet()`は`Parent`自身のprivateメソッドとして静的に解決されるため、`Child`に何も追加しなくても`"Parent"`が出力される」

**B.**
```java
private void greet() { System.out.println("Child"); }
```
「これはオーバーライドとして成立し、動的束縛によって`"Child"`が出力される」

**C.**
```java
private void greet() { System.out.println("Child"); }
```
「これはオーバーライドではなく無関係な別メソッドとして扱われるため、`Parent.run()`経由では常に`"Parent"`が出力される」

**D.**
```java
public void greet() { System.out.println("Child"); }
```
「アクセス修飾子を広げてオーバーライドしているので、動的束縛によって`"Child"`が出力される」

---

## 解答

正解：**A, C**

- **A**：正しい。`Child`に何も追加しなくても、`Parent.run()`内の`greet()`は`Parent`自身のprivateメソッドとして静的に解決される。
- **B**：誤り。`Child`が同じシグネチャの`private greet()`を追加しても、それは継承・オーバーライドの対象外の「無関係な別メソッド」でしかない。`Parent.run()`から見える`greet()`は依然として`Parent`自身のもの。
- **C**：正しい。Bと同じコードだが、こちらの説明が正しい。privateメソッドは動的束縛（オーバーライド）に一切参加しないので、`Parent.run()`経由では常に`"Parent"`が出力される。
- **D**：誤り。`Child`側でアクセス修飾子を`public`に広げても、`Parent`の`greet()`は元々`private`で不可視だったため、これは依然として「オーバーライドではなく無関係な別メソッド」。**親のメソッドが不可視（private）である時点で、子側がどんなアクセス修飾子（`public`含む）で同名メソッドを定義しても、オーバーライドは成立しない**。オーバーライドの可否を決めるのは子側の修飾子の広さではなく、親のメソッドが子から見えているかどうかという一点だけ。

A/B/D（それぞれ`Child`側の宣言違い）をすべてjavac/javaで実機検証済み：全パターンで出力は`"Parent"`。
